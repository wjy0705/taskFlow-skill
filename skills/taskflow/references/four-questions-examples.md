# 四问示例 v0.3.0

这些示例用于帮助落地 Task Flow 的状态追踪和实际对话。示例里的工具、命令和 skill 都要按当前项目和当前会话真实可用能力替换。
注意示例中引入的强制状态头 `[当前阶段：X. XXX]`。

## 示例 1：修 bug (带有断点确认)

### 1. 我真的理解了吗？
```markdown
[当前阶段：1. 我真的理解了吗？]

**复述**：用户登录成功后页面白屏，需要找出白屏原因并修复。
**上下文**：读取路由守卫、登录回调、用户信息接口和最近相关 diff。
**复现**：登录后页面空白，console 无明显报错，目标组件没有渲染。
**边界**：不能改变登录接口契约，不能破坏已登录用户跳转逻辑。

> ✋ **需要确认**：我怀疑是昨天的 Vue Router 升级导致的守卫拦截死循环。我是否可以先去修改 `router/index.js` 中的鉴权逻辑？(请回复 Y/N)
```

### 2. 我用对能力了吗？
```markdown
[当前阶段：2. 我用对能力了吗？]

**能力计划**：
- 能力：前端路由诊断 + 最小代码修复
- 手段：重写 `beforeEach` 守卫逻辑
- 验证：执行本地 `npm run build` 确保无编译报错。
```

### 3. 结果有证据证明对吗？

`\u200b`\u200b\u200b
