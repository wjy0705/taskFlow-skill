# 四问示例

这些示例用于帮助落地 Task Flow。示例里的工具、命令和 skill 都要按当前项目和当前会话真实可用能力替换，不要照抄名称。

## 示例 1：修 bug

### 1. 我真的理解了吗？

```text
复述：用户登录成功后页面白屏，需要找出白屏原因并修复。
上下文：读取路由守卫、登录回调、用户信息接口和最近相关 diff。
复现：登录后页面空白，console 无明显报错，目标组件没有渲染。
边界：不能改变登录接口契约，不能破坏已登录用户跳转逻辑。
```

### 2. 我用对能力了吗？

```text
需要的能力：故障复现、前端路由诊断、最小代码修复、浏览器验证。
可用 skill：如果当前环境有调试或前端验证 skill，读取并按说明执行。
不用的能力：不需要文档生成，不需要数据库迁移。
```

### 3. 结果有证据证明对吗？

```text
diff：只修改路由守卫相关逻辑。
构建：前端构建通过。
浏览器：重新登录，不再白屏，跳转到目标页面。
console：无新增错误。
```

### 4. 卡住了怎么办？

```text
如果仍然白屏：回到第 1 问，检查组件懒加载、权限数据和接口响应。
如果三轮仍失败：报告已排查的方向、仍失败的证据、需要用户提供的环境或账号信息。
```

## 示例 2：加接口

### 1. 我真的理解了吗？

```text
复述：新增用户注册接口，接收 username、password、email，返回注册结果。
上下文：读取现有 Controller、Service、Mapper、用户表结构和统一响应格式。
边界：密码必须加密，邮箱不能重复，返回结构沿用项目约定。
```

### 2. 我用对能力了吗？

```text
需要的能力：后端实现、参数校验、数据库写入、接口验证、回归测试。
可用 skill：如果当前环境有测试先行、后端验证或项目规范 skill，按需使用。
```

### 3. 结果有证据证明对吗？

```text
构建或测试：项目后端测试/编译通过。
curl 正向：注册成功，响应结构正确。
curl 异常：重复邮箱返回预期错误；空密码返回预期错误。
数据库：新增用户写入正确表，密码不是明文。
```

### 4. 卡住了怎么办？

```text
500 错误：回到第 1 问，读日志和调用链，不猜。
密码加密方式不确定：读取现有登录或用户创建逻辑；仍不确定则问用户。
```

## 示例 3：代码审查

### 1. 我真的理解了吗？

```text
复述：审查当前改动，找出会导致 bug、回归、安全或可维护性问题的点。
上下文：读取 diff、PR 描述、被改文件周围代码和相关测试。
边界：只输出审查发现，不擅自修改代码，除非用户要求。
```

### 2. 我用对能力了吗？

```text
需要的能力：代码审查、风险判断、测试缺口识别。
可用 skill：如果当前环境有审查 skill，按它的输出格式和严重级别要求执行。
```

### 3. 结果有证据证明对吗？

```text
每个发现包含：文件路径、行号、问题、影响、建议。
没有问题时说明已检查范围和剩余风险。
```

### 4. 卡住了怎么办？

```text
设计意图不清楚：提出一个最小必要问题。
风险无法确认：标记为不确定，不把猜测写成结论。
```

## 示例 4：探索项目

### 1. 我真的理解了吗？

```text
复述：用户想理解这个项目的技术栈、入口、核心模块和运行方式。
上下文：读取 README、目录结构、包管理文件、配置文件和入口文件。
边界：不修改代码，只做结构说明。
```

### 2. 我用对能力了吗？

```text
需要的能力：项目结构探索、代码阅读、总结。
可用工具：优先使用快速文件搜索和项目已有文档；有代码图谱工具时可辅助。
不用的能力：不需要 bug 诊断，不需要测试先行。
```

### 3. 结果有证据证明对吗？

```text
输出包含：技术栈、入口文件、核心模块、配置位置、运行命令。
每个结论能对应到实际文件。
```

### 4. 卡住了怎么办？

```text
入口不唯一：列出候选入口和证据，让用户确认关注方向。
项目太大：先给顶层模块图，再深入用户指定部分。
```
